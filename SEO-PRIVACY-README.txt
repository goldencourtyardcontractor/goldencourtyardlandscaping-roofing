Therefore, the robots.txt included inside this project repository may NOT control crawlers while the site remains under the GitHub project subpath. The HTML noimageindex rule is the main privacy-oriented search directive in this package.

Anything displayed by a public website is public to people who know the URL. Crawler rules reduce indexing; they do not make media confidential.
